# 帮我看看（父母端识图）

父母端多模态能力：给可可一张图，可可看完之后用**同一条流式语音**继续聊。

与 [`doc/需求.md`](需求.md) 的偏差：29.1 曾把「帮我看看」整体推到 V1.5。本文按用户当前要求纳入；识图后追问已并入 Realtime 语音陪伴，不再走独立 ASR/TTS。

## 心智模型

「看照片 / 看眼前」不是另一套对话，只是给可可递一张图。读完图之后，听、想、说全部走现有 Realtime（`qwen-audio-3.0-realtime-plus`），和点「说话」是同一次陪伴。

| 工具 | 含义 | 取图 | 本期 |
| --- | --- | --- | --- |
| 说话 / 对话中 | 语音陪伴 | — | 已有 |
| 看眼前 | 眼前实物 | 系统相机 | **已落地** |
| 看手机 | 手机上的内容 | 截屏 / 读屏相关 | 占位，下期 |
| 看照片 | 相册里的照片 | **直接系统相册**，无自定义弹层 | **已落地** |

流程在**父母首页原地完成**：

```text
点「看照片」或「看眼前」→ 取图 → 首页显示照片 +「可可正在看」
  → 多模态读图 → 接通/复用 Realtime → 注入读图上下文 → 可可开口讲
  → 收起照片，继续语音陪伴（「字」、打断、确认大卡与说话一致）
```

- **没有**「换一张」按钮；要换图就再点一次「看照片 / 看眼前」。
- 「看照片 / 看眼前」是一次性动作，只短暂按压反馈，**不保持高亮**。
- 未通话时选图成功会**自动接通**语音，不必再点「说话」。

## 范围

| 阶段 | 内容 |
| --- | --- |
| 本期 | 首页「看照片」「看眼前」→ 识图 → 注入 Realtime；「看手机」占位 |
| 后续 | 看手机完整 UI；识图结果接创建提醒、分享给子女；iOS Share Extension |

## 技术链路

```text
取图 → POST /v1/vision/look（qwen3.7-plus）→ scene_description
  → WS /v1/voice/realtime
  → 客户端 vision.inject
  → session.update（照片块写入 instructions，换图整块替换）
  → response.create → 可可口语播报
```

- 识图仍用多模态 `COCO_VISION_MODEL`（默认 `qwen3.7-plus`）。
- Realtime **不看原图**，只消费读图文本，避免音频模型与视觉模型绑死。
- 主路径**不再**调用 `POST /v1/vision/follow-up` 与独立 ASR/TTS；追问留在语音会话内。
- 后端 follow-up 接口可保留，但不接首页主路径。

## 页面与状态

| 位置 | 说明 |
| --- | --- |
| `/parent` 首页原地 | 分析中显示照片；可可开口后回到陪伴形象 |
| `/parent/look` | 旧独立页，仅兼容/调试，主路径不再从首页进入 |

要点：

- 分析中显示「可可正在看」；识图成功交接中可显示「看完了，接着和您说」。
- 「字」是全局偏好；读图原文**不**当作用户发言写入字幕。
- 失败：`这张照片没看清，请再试一次`；若本次为看图新开通话则挂断，避免空连。
- 再选图时取消旧识图任务，以最后一次为准。
- 分析中弱化/禁用「看手机」；「说话」仍可用。

## 接口

```text
POST /v1/vision/look          multipart: image + question?
  → { confidence, headline, detail, safety_note, scene_description, conversation_id? }

WS /v1/voice/realtime
  上行 vision.inject: { scene_description, source? }   # album | camera
  下行 vision.injected（可选确认）
```

相册首轮默认问题：`请帮我看看这张照片里有什么。`  
看眼前：`请帮我看看这是什么、上面写了什么。`

## 不可破坏的规则

- **图片不落库、不落盘**：只在内存中转发给识图模型；`conversation_items` 只写文本。
- **识图内容不写记忆**：药盒、账单、验证码等一次性信息；注入提示显式禁止对此类内容 `save_memory`。
- **不做医疗判断**：可读出药盒文字，不得解释疗效或建议剂量。
- **不承诺安全性**：不得把未知链接判定为绝对安全。

## 与现有能力的衔接

| 能力 | 本期做法 |
| --- | --- |
| 追问 / 播报 | Realtime 语音陪伴（与「说话」同一会话） |
| 提醒 / 关怀分享 | 仍走语音工具 + 确认大卡（与说话一致） |
| 记忆 | 照片一次性信息不写入；日常偏好仍按陪伴规则静默保存 |
| 对话历史 | LOOK 会话落库读图摘要；语音侧走 REALTIME 会话 |
