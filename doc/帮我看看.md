# 帮我看看（父母端识图）

父母端多模态能力：给可可一张图，可可看完之后跟你继续聊。

与 [`doc/需求.md`](需求.md) 的偏差：29.1 曾把「帮我看看」整体推到 V1.5。本文按用户当前要求重新纳入；UI 以 [`doc/可可_UI完整交付_v2`](可可_UI完整交付_v2/README_AI开发说明.md)（2026-08-13）为准。成本最高的 iOS Share Extension 仍留在 V1.5。

## 心智模型

不再让老人先选「图片从哪来」的技术分类。首页底栏拆成四个工具，按**看什么**区分：

| 工具 | 含义 | 取图 | 本期 |
| --- | --- | --- | --- |
| 说话 / 对话中 | 语音陪伴 | — | 已有 |
| 看眼前 | 眼前实物 | 系统相机 | 占位，下期交付 UI |
| 看手机 | 手机上的内容 | 截屏 / 读屏相关 | 占位，下期交付 UI |
| 看照片 | 相册里的照片 | **直接系统相册**，无自定义弹层 | **本期落地** |

识图流程在**父母首页原地完成**，不跳转独立「看一看」页：

```text
点「看照片」→ 系统相册 → 首页显示照片 +「可可正在看」
  → 结论语音播报（「字」开则同屏显示文字）→ 可语音追问
```

- **没有**「换一张」按钮；要换图就再点一次「看照片」。
- 「看照片」是一次性动作，只短暂按压反馈，**不保持高亮**。
- 相对旧实现：取消独立 `/parent/look` 来源弹层（拍一张 / 截屏 / 相册三选一）作为主路径。

## 范围

| 阶段 | 内容 |
| --- | --- |
| V1（本期） | 首页「看照片」相册识图 + 自动朗读 + 同图多轮追问；「看眼前 / 看手机」按钮占位 |
| V1.5 | 看眼前 / 看手机完整 UI；识图结果接创建提醒、分享给子女；iOS Share Extension |

V1 不接提醒与分享：先验证识图准确率和老人能否用起来。

## 页面与状态

| 位置 | 说明 |
| --- | --- |
| `/parent` 首页原地 | 分析中、识别完成、失败提示；顶底固定，中间滚动 |
| `/parent/look` | 旧独立页，仅作兼容/调试，主路径不再从首页进入 |

交互细则、素材与验收见 [`可可_UI完整交付_v2/README_AI开发说明.md`](可可_UI完整交付_v2/README_AI开发说明.md)。

要点摘要：

- 分析中显示临时态「可可正在看」（非对话气泡）；完成后自动消失。
- 「字」是全局偏好，不因选图自动切换。
- 上传中：`照片正在上传`；失败：`这张照片没看清，请再试一次`（普通提示，不弹复杂窗）。
- 再选图时取消旧任务，以最后一次为准。
- 分析中弱化/禁用「看眼前」「看手机」，减轻一屏多主操作干扰；「说话」仍可用。

追问**不**跳回 realtime 语音陪伴，留在识图会话内用 `COCO_VISION_MODEL`。

## 接口

```text
POST /v1/vision/look          multipart: image + question?
POST /v1/vision/follow-up     JSON: { conversation_id, text } → { reply_text }
POST /v1/audio/transcriptions multipart: audio → { text }
POST /v1/audio/speech         JSON: { text } → audio/mpeg
```

识图与追问均走 `qwen3.7-plus`（`COCO_VISION_MODEL`）。首次 look 后原图进**进程内 TTL 缓存**（约 15 分钟，不落盘）；追问复用缓存图 + 历史文本。缓存过期（410）时提示再点「看照片」选图。

相册首轮默认问题：`请帮我看看这张照片里有什么。`（看眼前 / 看手机上线后各自带默认问题。）

ASR / TTS：

```env
COCO_ASR_MODEL=qwen-audio-3.0-asr-flash
COCO_TTS_MODEL=qwen-audio-3.0-tts-flash
COCO_TTS_VOICE=longanhuan
```

## 不可破坏的规则

- **图片不落库、不落盘**：只在内存中转发给模型 / 进 TTL 缓存；`conversation_items` 只写文本。
- **识图内容不写记忆**：药盒、账单等敏感一次性信息；追问提示词显式禁止 `save_memory`。
- **不做医疗判断**：可读出药盒文字，不得解释疗效或建议剂量。
- **不承诺安全性**：不得把未知链接判定为绝对安全。

## 与现有能力的衔接

| --- | --- |
| 追问 | 同 LOOK 会话 + ASR/TTS + vision follow-up；不进 realtime |
