# 帮我看看（父母端识图）

父母端多模态能力：给可可一张图，可可看完之后跟你继续聊。

与 [`doc/需求.md`](需求.md) 的偏差：29.1 曾把「帮我看看」整体推到 V1.5。本文按用户当前要求重新纳入，但只做 App 内的相机、相册与截屏；成本最高的 iOS Share Extension 仍留在 V1.5，与原顾虑一致。

## 心智模型

原型 v0.4 把这个模块按「图片从哪来」分成手机信息与现实物品两条平行流水线，共 7 屏。问题是让老人替系统做技术分类，且两套结果页语义相同、识别完是死胡同、全程没有语音参与。

本设计只有一条流程，**单页原地完成**：

```text
选来源（拍一张 / 最近截屏 / 相册）→ 自动识图 → 结论大字 + 自动朗读
  → 播完自动开麦 → 说完自动停 → 回答朗读 → 可反复追问
```

## 范围

| 阶段 | 内容 |
| --- | --- |
| V1 | 三种取图来源、单页识图 + 自动朗读 + 同图多轮追问（ASR/TTS 外壳） |
| V1.5 | 识图结果接创建提醒、接分享给子女、iOS Share Extension |

V1 不接提醒与分享：先验证识图本身的准确率和老人能否用起来，再决定往哪个业务落点接。

## 页面

入口在父母首页底栏 **「看一看」**（与「说话」并列）。

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/parent/look` | 看一看单页 | 取图、识图、结论、追问全在同屏；无子路由 |

「还想问」**不**跳回实时语音陪伴（`qwen-audio realtime`），而留在识图会话内用 `COCO_VISION_MODEL` 继续看图回答。

### 三种取图来源

来源只影响怎么拿图，以及首轮默认问题（传给 `POST /v1/vision/look` 的 `question`）：

| 来源 | 取图方式 | 首轮默认问题 |
| --- | --- | --- |
| 拍一张 | 系统相机 | 请帮我看看这是什么、上面写了什么。 |
| 最近截屏 | 读系统截屏智能相册最新一张；不可用时降级到相册选择器 | 请帮我看看这条消息在说什么，有没有需要小心的地方。 |
| 相册 | 系统相册选一张 | 请帮我看看这张照片里有什么。 |

### 交互（对齐首页语音）

- 识图完成后 **自动朗读** 结论，无需再点「还想问」进第二屏。
- 结论播完后 **自动开麦**；用户说完后本地静音判定（约 800ms）自动收手，也可点「我说完了」。
- 主按钮随阶段变化：点一下开始说 / 我说完了 / 打断 / 换一张。
- 次按钮：再听一遍、换一张。

## 接口

```text
POST /v1/vision/look          multipart: image + question?
POST /v1/vision/follow-up     JSON: { conversation_id, text } → { reply_text }
POST /v1/audio/transcriptions multipart: audio → { text }
POST /v1/audio/speech         JSON: { text } → audio/mpeg
```

识图与追问均走 `qwen3.7-plus`（`COCO_VISION_MODEL`）。首次 look 后原图进**进程内 TTL 缓存**（约 15 分钟，不落盘）；追问复用缓存图 + 历史文本。缓存过期（410）时页内提示重新拍一张。

ASR / TTS：

```env
COCO_ASR_MODEL=qwen-audio-3.0-asr-flash
COCO_TTS_MODEL=qwen-audio-3.0-tts-flash
COCO_TTS_VOICE=longanhuan
```

## 不可破坏的规则

- **图片不落库、不落盘**：只在内存中转发给模型 / 进 TTL 缓存；`conversation_items` 只写文本。
- **识图内容不写记忆**：药盒、账单等敏感一次性信息；追问提示词显式禁止 `save_memory`。
- **不做医疗判断**：可读出药盒文字，不得解释疗效或建议剂量。
- **不承诺安全性**：不得把未知链接判定为绝对安全。

## 与现有能力的衔接

| 能力 | V1 做法 |
| --- | --- |
| 追问 | 同 LOOK 会话 + ASR/TTS + vision follow-up；不进 realtime |
| 对话历史 | TOOL 摘要 + USER/ASSISTANT 文本轮次 |
| 记忆 | 显式不写入 |
| 提醒 / 关怀分享 | V1 不接 |
