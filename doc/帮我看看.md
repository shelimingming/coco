# 帮我看看（父母端识图）

父母端多模态能力：给可可一张图和一句话，可可看完之后跟你继续聊。

与 [`doc/需求.md`](需求.md) 的偏差：29.1 曾把「帮我看看」整体推到 V1.5。本文按用户当前要求重新纳入，但只做 App 内的相机与相册；成本最高的 iOS Share Extension 仍留在 V1.5，与原顾虑一致。

## 心智模型

原型 v0.4 把这个模块按「图片从哪来」分成手机信息与现实物品两条平行流水线，共 7 屏。问题是让老人替系统做技术分类，且两套结果页语义相同、识别完是死胡同、全程没有语音参与。

本设计只有一条流程，来源仅影响怎么拿到图：

```text
取图（拍照 / 相册 / 系统分享） → 一次识图 → 一个结论 → 可以继续说话
```

## 范围

| 阶段 | 内容 |
| --- | --- |
| V1 | 相机拍照、相册选图、识图结果页、结果页「还想问」接语音继续对话 |
| V1.5 | 识图结果接创建提醒、接分享给子女、iOS Share Extension |

V1 不接提醒与分享：先验证识图本身的准确率和老人能否用起来，再决定往哪个业务落点接。

## 页面

入口在 `parent_functions_page` 功能网格新增一格「帮我看看」；语音说「帮我看看这个」也可进入。

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/parent/look` | 取图页 | 相机取景占上半屏；主按钮「拍这张」，次按钮「从相册里选」 |
| `/parent/look/result` | 结果页 | 结论 + 说明 + 安全提示 + 动作区 |

取图页语音条常驻：老人举着手机说「看看这个还能不能吃」，这句话即为提给模型的问题。相册走系统单张选择器，iOS 上无需申请整个相册的读取权限。

识别中不单独成页，是按钮 loading 态 + Coco 切到 `looking` 姿态。

结果页四段结构，一屏一事：

| 区块 | 内容 | 样式 |
| --- | --- | --- |
| 结论 | 大字，最多两行，如「保质期到 2026年8月18日」 | 父母端主色 |
| 说明 | 一句话，如「今天还没有过期。」 | 正文 |
| 安全提示 | 条件出现，如「包装若鼓起、漏气或有异味，不要食用。」 | warning |
| 动作区 | `还想问` / `知道了` / `重新拍一张` | 主 + 次按钮 |

「看不清」是本页的一个状态而非独立页面：`confidence=low` 时不渲染结论，改为「我看不太清这上面的字」，动作区换成 `重新拍一张` / `让家人帮忙看`。

颜色、间距、圆角一律取 `frontend/lib/core/theme/tokens.dart` 的父母端 token，禁止页面内写裸色值。

## 接口

```text
POST /v1/vision/look    multipart: image + question? + conversation_id?
```

后端新增 `modules/vision/{router,service,schemas}.py`，provider 新增 `providers/qwen_vision.py`，复用百炼 OpenAI 兼容 `/chat/completions`，`content` 数组内以 base64 data URL 传图。

模型可配置，与既有模型变量并列：

```env
COCO_VISION_MODEL=qwen3.7-plus
```

`qwen-plus` 只支持文本输入，不能用于本功能。

按「大模型不直接控制页面、统一返回结构化结果」的约定，服务端返回结构化 JSON：

```json
{
  "confidence": "high | low",
  "headline": "保质期到 2026年8月18日",
  "detail": "今天还没有过期。",
  "safety_note": "包装若鼓起、漏气或有异味，不要食用。"
}
```

不确定性由模型通过 `confidence` 表达，前端据此切换渲染，不在客户端猜测。

## 不可破坏的规则

- **图片不落库、不落盘**：只在内存中转发给模型，请求结束即释放。`conversation_items` 只写文本摘要。
- **识图内容不写记忆**：药盒、账单、快递单、体检单均为敏感的一次性信息。视觉提示词须显式关闭 `save_memory`，避免被陪伴提示词第 7 条的强制记忆规则捕获。
- **不做医疗判断**：可以读出药盒上的文字，不得解释疗效、推荐剂量或建议停药。
- **不承诺安全性**：不得把未知链接、来源不明的通知判定为绝对安全。

## 与现有能力的衔接

| 能力 | V1 做法 |
| --- | --- |
| 语音对话 | 结果页「还想问」启动实时语音，开场 instructions 带上本次识图结论，可直接追问 |
| 对话历史 | 一次识图写一条 `conversation_items`，`kind=TOOL`，`display_summary` 形如「看了一张图：保质期」 |
| 记忆 | 显式不写入，见上节 |
| 提醒 / 关怀分享 | V1 不接。V1.5 复用现有 `create_reminder`、`share_to_child` 工具与确认大卡，无需新增确认机制 |
