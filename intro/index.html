真实问题

家庭缺少的不是关心，
而是让关心持续发生的低负担方式。

老人端：55—75 岁、生活基本自理、与成年子女异地居住。子女端：已离家工作或独立生活的成年子女。

缺口一

子女不在身边时，老人缺少随时可得的日常帮助。

缺口二

异地家庭缺少低负担的生活参与感，关心容易变成反复询问或长期沉默。

产品定位

补位 · 翻译 · 促联

可可是具象化的 AI 关怀 Agent：陪老人处理健康提醒和日常问题，把双方的自然表达转化为彼此更容易理解和回应的信息，最终促进微信、电话或线下的真人关怀。

补位

子女不在场时

帮助老人完成日常小事，让独立生活不那么孤单、也不那么难。

翻译

降低理解成本

降低老人与子女之间的表达与理解成本，让关心说得清、听得懂。

促联

回到真人联系

把信息转化为一次电话、微信或线下交流，而不是替代家庭关系。

边界：不扮演子女，不把老人变成监控对象，不替代医生、家属或急救服务。

两类价值 · 四项能力

同一个可可，自然进入不同能力

老人始终面对同一个可可，通过持续语音自然进入能力，不选择模式或 Agent。

子女不在身边时补位

健康守护

用药、饮水、吃饭、活动、复诊与自定义提醒。老人确认后生效；重要提醒经授权后才联系子女。

创建确认 → 主动提醒 → 语音反馈 → 必要时跟进

子女不在身边时补位

帮我看看

包装日期看不清、家电按钮不会用、短信或 App 弹窗看不懂——用说话、摄像头、直播屏幕或照片来解释。

自然提问 → 理解内容 → 简短可执行解释 → 风险处停止

建立家庭连接

关怀翻译

老人怕打扰、报喜不报忧；子女收到零散表达后不知道是否重要。可可先关怀，再经授权转化表达。

自然表达 → 关怀了解 → 授权同步 → 回到真人交流

建立家庭连接

安心同步

子女用语音或快捷状态报平安，老人听到自然、温暖的表达——不要求回复，不显示已读。

子女表达 → 温暖转述 → 合适时机告诉老人

CARE,
NOT CONTROL.

交互与机制适老

不是教老人适应 AI，
而是让 AI 适应老人。

让老人不必学习 AI

  • 一个可可，一个入口——不选择模式
  • 一屏一事，始终可以自由说
  • 能打断，也能接着来
  • 倾听、思考、说话、查看、提醒状态看得懂

少确认、少猜测、不过界

  • 低风险直接帮助，高影响动作确认
  • 健康与视觉双重安全分层
  • 记忆有连续性，也有边界
  • 只说可证实的结果，无回应不做推断

「可可不仅知道怎样帮助老人，也知道什么时候应该停下来。」

Agent 机制

通用 Agent 完成任务，
可可进一步决定何时关怀

在多模态输入 → 大模型理解 → 受控工具执行 → 真实结果反馈之上，增加三项特有机制。

  1. 关怀决策器 判断是否先回应感受，立即处理／当天汇总／不打扰，以及何时连接子女。
  2. 分层安全门 行动分层、健康分层与视觉放行／遮挡／阻断共同约束 AI。
  3. 陪伴记忆系统 区分当前对话、近期事件、稳定记忆和需确认的正式数据与行动。

第三种关系

关怀翻译

事实、感受、需求、回复预期和 AI 建议分开呈现，降低误判与压力。

双向参与

不仅子女了解老人，老人也能了解子女近况，参与彼此的日常生活。

促成真人联系

AI 处理理解与整理，真正关怀回到电话、微信和线下。
